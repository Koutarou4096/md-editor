# md-editor v1.3
Web上で動く簡易的なMarkdownエディタです。

[<img width="1920" height="1080" alt="image" src="https://github.com/user-attachments/assets/f61a1309-e080-439e-82bf-42a5c5547b7c" />](https://koutarou4096.github.io/md-editor/)


## 概要
- ワンクリックで太字にするなどの機能はありませんが、それ以外は一般的なMarkdownエディタと同じです。
- Markdown記法の練習や、簡単なメモといった用途を想定しています。
- プレビューの表示、.mdやHTML形式での保存、PDF化、印刷といった最低限の機能は入っています。
- 編集内容はブラウザ内に自動保存されます。誤ってページを再読み込みしたりタブを閉じたりしても、再度開いたときに内容が復元されます。<br>
    ※ 重要な内容を書いた場合は、念のため必ずファイルとして保存してください。
