# md-editor v1.5
Web上で動く簡易的なMarkdownエディタです。（以下、本ツールといいます）

## 概要
- 本ツールMarkdown記法の練習や、簡単なメモといった用途を想定しています。
- ワンクリックで太字にするなどの機能はありませんが、それ以外は一般的なMarkdownエディタと同じです。
- プレビューの表示、.mdやHTML形式での保存、PDF化、印刷といった最低限の機能は備わっています。
- 編集内容はブラウザ内に自動保存されます。誤ってページを再読み込みしたりタブを閉じたりしても、再度開いたときに内容が復元されます。
- **レスポンシブ対応はしていません。** 現時点ではPCでの使用のみを想定しています。

## 注意事項
本ツールでは不定期・予告なしにバージョンアップをすることがあります。バージョンアップでは、主にバグ修正、機能の追加・削除・改良を行います。バージョンアップ時にはWebページ自体を新しいものに差し替えるため、**ブラウザ内に保存されていたデータが消えることがあります。** そのため、重要な内容は、必ず`.mdを保存`または`HTMLを保存`でファイルとして保存してください。
